# (예시) 인터뷰 녹취 10건에서 반복 패턴 추출

지금의 전략: 녹취를 처음부터 읽으며 수기로 태그 붙이기 — 건당 약 1시간
AI 개선 가설: M05 프롬프트로 태깅 초안 자동화 → 내가 검수만. 검수 포함 건당 20분 목표
기준선 (시간·품질): 10건 = 약 10시간 / 놓치는 패턴 있음(다른 사람이 보면 새 패턴 발견)
유형: 🧩 해결하고 싶은 문제
상태: 🧪 실험 중
관련 모듈: M05 프롬프트
트랙: A 혁신 — 새 문제에 도전

## 실행 계획

로드맵에서 AI 피드백을 받아 확정한 계획을 여기 적습니다. 한 단계 = 데이 하나(작업 약 3시간) 분량으로 쪼개세요.

- [ ]  1차 데이: 태깅 프롬프트 3버전 작성 → 녹취 2건에 적용 → 수기 결과와 비교표
- [ ]  2차 데이: 놓친 태깅 유형 보강 → 나머지 8건 적용 → 건당 소요 시간 측정
